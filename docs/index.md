# Welcome to the MitoBee wiki!

This is a mitochondrial genome(mitogenome) recovery toolkit designed to evaluate and extract the host mitogenomes can be reconstructed from metagenomic datasets containing host-derived reads. The workflow is implemented using [Snakemake](https://snakemake.readthedocs.io/en/stable/) and [Snaketool](https://github.com/beardymcjohnface/Snaketool) cookie cutter profile.
